# Agents Anywhere 2.1.0

2.1.0 是接口更新（MINOR）：Runtime 命令协议新增字段，Runtime 实例数量限制的语义也变了。所有端的版本号都已更新为 `2.1.0`。本记录只说明源码和接口变化，不声明任何安装包已经发布。

## 产品变化

- **原生 `/compact`**：Codex 和 DSH 会话可以在输入框中执行 `/compact` 压缩上下文，时间线会显示压缩标记。Runtime 命令目录现在只保留 `/compact`；`/model`、`/permission` 等旧命令不再暴露，相关设置通过现有的选择控件修改。
- **限制同时运行的 Runtime 实例数**：`instancePolicy` / `maxInstances` 限制的是同时运行的实例数量，不再限制可以保存的配置数量。已经达到上限时再启动实例，会返回 `runtime_conflict`（HTTP 409）；停止一个实例后会释放名额。

## 接口变化

- Runtime 命令的 `metadata.ui` 用来描述交互方式（`execute` / `selector`），其中 `raw` 必须原样保留空白、换行和空字符串。
- `result.executionState` 的取值为 `accepted`、`completed` 或 `unknown`。确认回执丢失时，返回 `unknown`，并带 `retryable: false`。
- 能力 `session.commands` 可以携带 `metadata.catalogRevision`。客户端据此重新拉取命令目录。
- `contracts/runtime-control/2.0` 的 `instancePolicy` 改为限制同时运行的实例数量。

详细说明见 [Connector 与 Runtime 协议](../runtime-protocol/connector-to-runtime.md)、[Web 行为](../runtime-protocol/web-behavior.md) 和 [Runtime Control 契约](../../contracts/runtime-control/2.0/README.md)。

## 最低配套版本

| 端 | 最低版本 | 说明 |
| --- | --- | --- |
| Server、Connector | 2.1.0 | 需要一起升级，才能执行 `/compact` 并按同时运行数量限制实例 |
| DSH 插件 | 2.1.0 | DSH 会话需要它才能执行原生 `/compact` |
| Web、Desktop | 2.1.0 | 提供命令菜单和压缩标记；旧版本可以连接新 Server，但看不到这些功能 |
| Android、iOS | — | 本版本没有新增移动端命令界面；旧客户端按能力忽略新字段 |
